# API address
API addresses are differentiated according to region (CID) and live&non-live, with the following rules:
## 
Non-live: https://test-stable.spx.{{CID}}/
(Example：https://test-stable.spx.vn/、https://test-stable.spx.co.th/、https://test-stable.spx.sg/、https://test-stable.spx.co.id/、https://test-stable.spx.com.my/)

## Live: https://spx.{{CID}}/
(Example：https://spx.vn/、https://spx.co.th/、https://spx.sg/、https://spx.co.id/、https://spx.com.my/)

## NOTE:
Replace {{host}} in the http url with this address.
